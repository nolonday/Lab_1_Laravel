# Учебный сайт на Laravel

Учебный проект по серверной веб-разработке. В приложении реализованы несколько страниц на Laravel с общим Blade-макетом, маршрутизацией и динамическим выводом контактных данных.

## Реализовано

- Общий макет с меню, основной областью и подвалом.
- Главная страница-приветствие.
- Страница «О нас».
- Страница «Контакты»: данные передаются из маршрута в Blade-шаблон и выводятся циклом.
- Адаптивное оформление сайта.

## Страницы

| Адрес | Содержание |
|---|---|
| `/` | Главная страница |
| `/about` | О проекте |
| `/contacts` | Контактные данные |

## Запуск

Требуются PHP 8.3 или новее и Composer.

```bash
composer install
php artisan serve
```

Откройте адрес, указанный Artisan (обычно `http://127.0.0.1:8000`).

Для запуска тестов:

```bash
php artisan test
```

## Используемые технологии

- PHP и Laravel
- Blade
- HTML и CSS
